## About The Project

I am creating my own 16 bit computer from scratch. This includes the architecture, the data path design, the hardware design, and (maybe) a functional version build on bread boards.

I am using the 32 bit RISC-V architecture and instruction set as a jumping off point. Naturally, I can't fit nearly as much into half as many bits, so sacrifices will be made in the name of progress.

Below is a road map to track my current progress though the process, and I will keep this repo as up to date as possible.
